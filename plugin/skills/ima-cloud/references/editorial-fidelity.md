# 保真与可读性规则

适用于用户提供素材后的知识卡提炼、拆分、合并、改写与审定。目标是让读者准确理解素材的重要思想，并能回到原出处。忠实呈现观点与认可其真实性是两项独立判断。

## 先抓住素材的价值

阅读全文，在内部列出作者要解决的问题、一句话核心主张、支撑它的论证、独特例子或方法、关键条件。不是每篇都有全部项目；按实际内容取舍。这份提纲应能解释“这篇材料比一般常识多提供了什么”。

- 保留有辨识度的观点、比较对象、因果链、操作方法和关键例子。核心来自机制解释或场景时，保留解释和场景，不能只留一个抽象结论。
- 每次整理与补充前，必须按[主卡规则](topic-cards.md)完成整个目标库的登记、原生双检索和候选正文比对，再按知识2.0识别具体对象；同一事物的问题放入同一完整主卡的小节。每份来源保留可辨认的主张、论证、背景与定位；不同主张在同一对象内分别归属并说明分歧，范围不同的对象独立建立并关联。
- 多来源及新补充与现有主卡一起整合重写，形成完整正文，不在卡尾堆叠补丁；逐项标明来源，仍能找回各自核心主张、独特论证、方法、背景与历史。综合不能抹掉争议或覆盖原稿。已有卡写入和收拢通过新归并编排，不使用旧 ingest 更新替代。
- 没有读到原始素材时，明确正在整理现有 AI 摘要；不能据此宣称已保留原作全部核心价值。

## 把观点讲清楚

整理卡标题遵守[主卡命名](topic-cards.md#标题与对象边界)：概念只用词汇，具体事物用稳定名称，无法归入具体事物的独立问题用完整问句；不沿用文章标题生成重复主卡。来源原题保留在出处及原件，archive 标题与原貌保持不变。开头直接给出对象的当前答案，逐项说明作者主张及适用范围。

正文通常按“核心主张 → 为什么 → 关键例子或原文方法 → 必要补充与来源”展开，按素材内容增删层次，不强塞空栏目。用完整句表达判断，让读者能复述“作者认为 A，因为 B，因此提出 C”。日常词优先；必要术语首次出现时简短解释。每段承担一个清楚的意思。

篇幅取决于保留完整论证所需的信息量。去掉重复、绕口和与主题无关的铺陈，保留让观点成立和容易理解的内容。不要为了短卡、固定字数或统一模板，把独特观点抹成“因人而异、注意适量、综合考虑”等空泛结论。

建议只在原文确实提出方法时列“怎么做”；AI 新增的方法单列为“AI 补充”，附依据。标题由外层生成时，正文避免再次重复同名一级标题。读者正文不展示流程话术或机器元数据；核验状态在需要时用一行说明。

## 核查补充独立呈现

- 默认以“作者主张/作者认为”标明观点归属，在正文完整呈现其意思。原文中的事实判断按实际证据标注支持程度，不能因为保留原意就将其认证为事实。
- 发现疑点时，保留“原文主张是什么”，随后在“核查补充”中说明疑点、具体证据、适用条件及尚缺什么。若证据已与原文冲突，清楚写出冲突；不能为了让正文看似通过核查，静默把作者主张换成另一个结论。
- 仅在有证据且不改变原意时直接修正错字、明显单位错误等；影响核心意思、量词强度、因果、人群、时间或行动方向的修正必须显式说明。用户要求纠偏稿时也保留改动对照。
- 与主张密切相关的限制紧跟相应断言；共通背景及非关键提醒放后面，避免多段泛化声明遮住主题。必要风险信息仍要保留。
- 使用知识2.0的材料性质和核查状态：事实缺证据时保持待核查，观点与经验说明归属和情境。保留作者观点不能替代其中事实说法的核查，也不能捏造审核、来源或核查时间。

## 改稿前后的保真检查

在内部逐项核对，只有存在实质变化或用户要求审稿时才展示对照表：

1. 核心主张能否与原文对应，判断方向与强度是否保留？
2. 支撑主张的关键论证、独特例子和方法是否仍在？
3. 原作者观点、来源事实、AI 补充及核查异议是否可区分？
4. 删除、合并或改变的核心信息是否有明确理由并告知用户？
5. 不读原稿的人是否能讲清“作者说什么、为什么、怎么理解”？

任何一项不满足，先修订候选正文。文风大改、核心主张修正或批量重做旧卡时，先在对话展示一张真实素材的对照样稿和重要变化；样稿本身不写回 ima。用户已明确授权具体批次和风格时直接按该范围执行，无需逐卡重复确认。单纯反馈文风不等于授权覆盖或删除全部旧卡。
