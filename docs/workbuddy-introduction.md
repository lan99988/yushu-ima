# 在 WorkBuddy 里用一个会查证的知识库

同一个问题，你可能问过不止一次：去年查过一次，今年重新查，答案还是散的——一半在聊天记录里，一半在收藏夹里，剩下那些不知道当时是从哪看到的。

这套东西换个思路：**让每个问题只沉淀成一张卡，每次写入前先查证，写完读回来确认。**

## 它和"AI 帮你记笔记"不一样

差别在三个动作上，都是默认执行的：

**写之前先查。** 不是先写再想，而是先在整个库里查两遍——查已登记的对象，也查库里的原始资料。查到同一件事，就更新那张卡；只有确实没有，才新建。所以不会出现「鱼油」和「鱼油的吃法」两张互不相干的卡。

**同一件事只有一张卡。** 吃法、选购、禁忌，全部写进《鱼油》的小节里；《蛋白粉》另起一张。概念标题只写名称，独立的问题才用完整问句。

**写完读回来。** 保存不是终点。要看真实正文能不能读回来、内容对不对、有没有混进不该出现的内部信息。读不回就不算完成。

## 遇到文章里的说法，它会去查论文

这是它和普通剪藏工具最大的区别。

你丢一篇讲「喝咖啡能减脂」的文章进来，它不会照抄。它会先把文章的主张拆出来，再去对照原始研究：

- 科学结论只认论文和系统综述，新闻、营销、科普不算证据
- 主动去找相反结果，不只看支持自己的那篇
- 判断允许是「不支持」「证据不足」「有分歧」，不硬凑成肯定
- 会写清哪篇读了全文、哪篇只读了摘要，不把摘要核对说成全文核对

结果就是卡片里会留下这样的句子：「咖啡因确实小幅提高能量消耗，但 13 项随机试验合并后体重差异只有零点几公斤，研究间异质性 91%–94%」——而不是「每天四杯，一个月瘦十斤」。

## 装上，一条命令

前面这些能力装在 WorkBuddy 里，只需要三个值：服务地址、网关令牌、桥令牌。知识库 ID 不用填，它绑定在服务端。

```text
python scripts/install-workbuddy.py --url "https://你的站点/bridge/v1/mcp" --service-token "网关令牌" --bridge-token "桥令牌"
```

脚本会把技能复制到 `~/.workbuddy/skills/ima-cloud`，把服务写进 `~/.workbuddy/mcp.json`（已有的其他服务保留，原文件备份成 `mcp.json.bak`），并用当前 Python 的路径填好启动命令，不用手改。

不装 Node、不构建、不建数据库。只要 Python 3.11 以上。

重开一轮对话，在连接器里信任它，然后问一句「查一下我的知识库里有哪些目录」。能列出真实目录，就通了。

## 用起来是什么样

丢一段材料给它，说「整理入库」，实际发生的是：

1. 读你给的材料，提取里面能检验的主张
2. 在整个库里查两遍，看有没有同一件事的卡
3. 有卡就重写那张卡，没有就新建
4. 对主张去查论文，给判断，标清读了多少
5. 写成一张有结论、有证据、有出处的卡
6. 读回来核对，确认真的写进去了

你收到的是「已保存到《咖啡因》，第 1.3 版」这样的结果，加上一句缺口说明——比如「有两条来稿数字在论文摘要里查不到，标了待查」。

## 几个看着像出错、其实正常的现象

用起来会遇到一些状态，不理解容易误判：

| 现象 | 实际情况 |
|---|---|
| 改完之后文件 ID 变了 | 正常。ima 没有原位改写，改就是新建一版再删旧版 |
| 删除显示「核对中」 | 正常。派发后要做全库缺席扫描，推进完才有四项校验 |
| 提示 `ima_openapi_readback_incomplete` | 预览阶段遇到索引滞后，**没有真的派发**，重试同一次即可 |
| 说「卡片已改变」但你没动它 | 服务端会异步补上文件校验值，属于允许的漂移 |

这些判断都写在仓库的 [实操经验](../workbuddy/PLAYBOOK.md) 里，含每种状态该往哪一步走。

## 边界在哪

**不做原位改写。** ima 只提供删和查，没有改。所以「更新」实际是新建一版、删掉旧版，版本号递增，文件 ID 会变。系统内部按条目追踪，你感觉不到；但如果你别处硬编码过文件 ID，会失效。

**图片有单独的门禁。** 上传成功不等于在 ima 里显示成功，要真实的截图和重开证据。没过门禁会明确返回待验收，不会假装成功。

**归并有上限。** 每批最多 20 个来源、正文 1 MiB。超过就分批。

**服务要自己准备。** 仓库给的是规则和实现，不给别人账号的访问权。要自己部署一套，或者向已经部署的人要那三个值。

## 适合谁

如果你在某个领域持续积累——健康、投资、育儿、技术选型——并且希望「下次问同一个问题时，拿到的是更新过的同一个答案，而不是又一轮重新搜索」，这套东西是合适的。

如果你只是想存链接、做剪藏、随手记，它偏重了：检索、查证、读回核对这些步骤对随手记是负担。

一句话概括：**它不替你思考，但会让你的每个结论都有出处，并且只留一份。**
